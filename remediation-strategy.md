# Mythborn Remediation Strategy

1. Preserve the current handling of legacy jewelry URLs. They return 410 Gone with `X-Robots-Tag: noindex, nofollow`, are absent from the sitemap, and are not active routes. Do not redirect them into unrelated astrology pages, because that would blur intent and risk soft-404 or brand confusion.

2. Remove the global sponsored-links marquee from Mythborn pages. It exposes Teyfik, CTSEG, QCT Studio, and QCT Commerce as a prominent network inside an otherwise independent consumer product. Removing the band improves brand independence, avoids irrelevant cross-link prominence, reduces visual noise, and leaves the actual Mythborn footer navigation intact.

3. Keep the dedicated partner/selected-project content only where it is intentionally part of a page’s editorial architecture; do not remove the current Mythborn product or knowledge content.

4. Search Console removal requests remain an optional manual follow-up for the user because they require the verified property account. The technical site state is already correct for natural deindexing.

No unrelated design, mobile navigation, performance, or content changes are included.
